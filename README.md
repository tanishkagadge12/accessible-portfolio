# Accessible Personal Portfolio Website

## Overview

This project is a multi-page personal portfolio website developed using semantic HTML5 and WCAG accessibility guidelines.

## Features

* Semantic HTML5 structure
* Accessible navigation
* ARIA labels
* SEO-friendly meta tags
* Keyboard navigation support
* Responsive layout
* Accessible contact form

## Pages

* Home
* About
* Projects
* Contact

## Technologies Used

* HTML5
* CSS3

## Accessibility Features

* Skip navigation link
* Focus indicators
* Form labels
* Semantic landmarks
* Screen reader friendly structure
